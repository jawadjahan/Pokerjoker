# Poker Balance Tracker

A browser-based poker money/balance tracker.

## Run
Open `index.html` in Chrome/Edge/Firefox.

No server or installation is required.

## Main features
- Add players and starting balances
- Small/big blind setup
- Live bet, call, raise, check, fold and all-in controls
- Automatic pot and current-bet calculation
- Round winner selection
- Split pot for multiple winners
- Automatic player balance updates
- Win/loss and net profit tracking
- Round history
- LocalStorage persistence
- Mobile-friendly layout

## Important
This is a money/accounting tracker, not a poker-rule engine. It does not determine the poker hand winner. The user selects the winner(s) after each round.

## APK
To turn this web app into an Android APK without Android Studio, upload the project folder/ZIP to a trusted web-to-APK/PWA packaging service. Before installing an APK, review the service and permissions carefully.
